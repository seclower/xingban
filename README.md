# 安全守护 - 智能人身安全卫士

## 项目背景

在大连理工大学城市学院鼓励科技创新、服务社会需求的创新创业氛围下，我们团队聚焦于传统安全防护手段的被动与滞后性问题，开发了一款以"主动安全预警"为核心，以"轻度情感陪伴"为辅助的创新型应用。

## 产品形态

本APP是一款界面清新、布局直观的移动应用，采用蓝紫色调为主，营造科技感与安心感并重的视觉体验。主要包含四大核心模块：

1. **首页**：智能守护仪表盘，展示安全指数和六大核心功能入口
2. **安全页**：专业工具集合，包含紧急联系人管理、安全设置和安全演练记录
3. **情感页**：轻量陪伴空间，用于用户与AI伙伴进行日常互动和查看情绪记录
4. **我的页**：个人设置与管理，包含账户设置、隐私权限控制等

## 核心功能

### 核心安全守护功能
1. **智能情境感知与主动预警引擎**：7x24小时后台运行，分析用户对话内容和实时位置，动态评估风险等级
2. **一键式紧急响应系统**：包含一键通知紧急联系人、AI智能辅助取证、紧急电话智能建议
3. **安全情景模拟与演练**：内置高频风险场景的模拟模块，提升用户自救能力

### 辅助性情感与粘性功能
1. **轻量化情绪记录与安全日志**：快速记录日常情绪，生成安全行为分析报告
2. **安全知识互动游戏**：以轻松方式提升用户的安全意识和心理素质

## 技术实现

- **前端**：HTML5 + Tailwind CSS + Font Awesome
- **AI集成**：预留百度AI API接口，可实现情感分析和智能预警
- **响应式设计**：适配不同屏幕尺寸的移动设备

## 快速开始
