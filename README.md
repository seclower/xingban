# 星伴守护 - 智能安全保护应用

一个专注于用户安全保护的Web应用，提供紧急求助、AI陪伴、情景模拟演练等功能。

## 🌟 主要功能

### 🔐 安全保护
- **SOS紧急求助**：一键发送求助信息，通知紧急联系人
- **位置守护**：实时位置共享，行程保护
- **智能取证**：录音录像功能，保护证据安全

### 🤖 AI智能陪伴
- **7×24小时聊天**：AI助手全天候在线陪伴
- **安全咨询**：提供专业安全建议
- **情感支持**：倾听您的心声，给予安慰

### 📚 安全知识
- **情景模拟**：打车安全、独居防护、社交边界等演练
- **安全游戏**：趣味学习安全知识
- **资源库**：丰富的安全知识内容

### 👥 社区互助
- **经验分享**：交流安全经验
- **求助咨询**：寻求帮助和建议

## 🚀 快速开始

### 方式一：使用启动脚本（推荐）
1. 双击运行 `启动应用.bat`
2. 等待服务启动
3. 浏览器自动打开访问页面

### 方式二：手动启动
1. 启动后端API服务：
```bash
python server.py
```

2. 在浏览器中打开：
```
http://127.0.0.1:8082
```
